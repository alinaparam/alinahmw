Part 1used to · would · be / get used to
1

Habits: then and now

used to + V: было раньше, сейчас нет (привычки и состояния). would + V: только повторяющиеся действия.
⚠️ После did / didn’t пишем use to без -d: I didn’t use to… · Did you use to…?
be used to + -ing: уже привыкла · get used to + -ing: привыкаю.
